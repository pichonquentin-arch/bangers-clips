Bangers Clips

Bangers Clips is a small desktop tool used by the GTA_Bangers channel. It takes short vertical clips of my own gameplay, recorded on my own console, and uploads them to my own TikTok account, with a caption.

How it works

  1. I sign in once with my TikTok account through TikTok Login Kit and authorize the app.
  2. The tool reads my basic profile information to show which account is connected.
  3. For each new clip, the tool sends the video file to TikTok with the Content Posting API, with the caption and privacy setting I chose.

The tool only posts content that I created myself. It does not collect data about other TikTok users.
